# 🏹 श्रीराम चरित यात्रा | Ramayana Journey & Ancient India Map

An interactive, high-fidelity cartography and narrative web application visualizing the ancient geopolitical landscape of the Indian subcontinent (Bharata Varsha) during the Treta Yuga and tracing the complete journey of Bhagavan Sri Rama from His divine advent in Ayodhya to the scriptural conclusion in the Uttara Kanda.

## 🌟 Key Highlights & Features

### 1. Dual-Layer Geospatial Cartography
* **Ancient Janapadas & Realms**: Polygons, capitals, rulers, and historical notes for ancient kingdoms:
  * *Northern*: Kosala, Videha (Mithila), Kekaya, Gandhara, Anga, Magadha, Kashi
  * *Forest Frontier*: Nishada Realm, Vatsa, Dandakaranya primeval wilderness, Janashthana
  * *Southern*: Kishkindha (Vanara realm), Dravida realms (Chola, Pandya, Chera), Island citadel of Lanka
* **Modern Subcontinent Overlay**:
  * Toggle modern Indian states (UP, Bihar, MP, Maharashtra, Karnataka, Tamil Nadu, Andhra Pradesh, etc.) and neighboring countries (Nepal, Sri Lanka, Pakistan, Bangladesh) to see the exact relationship between ancient events and today's geography.
* **Map Themes**: Switch between **Cosmic Dark**, **Antique Parchment / Voyager**, and **Topographical Physical Terrain**.

### 2. Complete 28-Milestone Narrative Roadmap (Birth to Scriptural Conclusion)
* Covers all 7 Kandas of the epic:
  1. **Bala Kanda**: Divine birth in Ayodhya, Vishwamitra yajna protection at Siddhashrama, Ahilya redemption, Sita Swayamvara in Janakpur, Parashurama meeting.
  2. **Ayodhya Kanda**: Exile proclamation, Tamasa night halt, Guha & Kevat Ganga crossing at Shringaverapura, Prayag Bharadwaja hermitage, Chitrakoot hermitage & Bharata Milap with the sacred Padukas.
  3. **Aranya Kanda**: Atri-Anasuya ashram, sages of Dandakaranya, Agastya ashram, Panchavati on Godavari, Surpanakha, golden deer Maricha, abduction of Sita, Jatayu's valorous battle and liberation.
  4. **Kishkindha Kanda**: Pampa Sarovar & Shabari, meeting Hanuman & Sugriva at Rishyamukha, Vali Vadha, southern ocean arrival & Sampati's revelation.
  5. **Sundara Kanda**: Hanuman's oceanic leap, Ashoka Vatika discovery, signet ring delivery, and burning of Lanka.
  6. **Yuddha Kanda**: Vibhishana Sharanagati, building of Ram Setu, epic siege of Lanka, Ravana Vadha, Agni Pariksha, aerial return via Pushpaka Vimana, and grand Pattabhishekam in Ayodhya.
  7. **Uttara Kanda**: Golden era of Rama Rajya, Sita at Sage Valmiki's ashram, birth of Lava & Kusha singing the Ramayana, Sita's return to Mother Earth (Bhu-Devi), and Sri Rama's concluding ascension in the holy Sarayu River (*Mahaprasthana*).

### 3. Dual-Scripture Integration
* Direct canonical citations for both:
  * **Valmiki Ramayana**: Sanskrit Shlokas in Devanagari with English translations and specific Sarga citations.
  * **Tulsidas's Ramcharitmanas**: Awadhi Chaupais and Dohas with Hindi/English meanings.

### 4. Interactive Tools
* **Auto-Tour / Playback Mode**: Step sequentially through the epic journey with smooth camera fly-to transitions.
* **Timeline Scrubber**: Jump between milestones or filter by Kanda.
* **Comprehensive Search**: Search by ancient realm, modern city, character name, or event.
* **Epic Chronicle Book Reader**: Full-screen reader mode for reading the epic chronologically.
* **Web Audio Tanpura Drone**: Built-in soothing harmonic ambient drone (synthesized natively via the Web Audio API without external dependencies).

## 🛠️ Tech Stack

* **Framework**: React 18 + Vite 6 (TypeScript)
* **Styling**: Tailwind CSS + Lucide Icons + Google Fonts (*Cinzel*, *Yatra One*, *Inter*)
* **Map Engine**: Leaflet with custom DivIcons, vector polygons, and polyline route layers
* **Audio**: Native Web Audio API harmonic oscillator synthesis

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/trojanh/ramayana-journey-map.git
cd ramayana-journey-map

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
